# Documentação

## Plano de Gerência de Configuração de Software (GCS)

O plano de GCS é um **item de configuração**: fica versionado neste repositório e só muda
por Pull Request revisado.

| Documento | Descrição |
|---|---|
| [gcs/N2_Felipe_Schwabe_Eduardo_Gabriel_Macedo.pdf](gcs/N2_Felipe_Schwabe_Eduardo_Gabriel_Macedo.pdf) | Avaliação N2 — escolha de processos (Incremental, Scrum, Ágil/fluxo contínuo) para dois domínios, com rastreabilidade, baseline, CCB, branches de release/hotfix e GCS integrada |

Resumo dos pontos de GCS do documento: ID único de requisito ligado a item de trabalho, commit,
pull request, testes, versão e aceite; baseline por incremento identificada por tag imutável e
release; Comitê de Controle de Mudanças (CCB) para o núcleo; proteção de branch e pull requests;
hotfix testado, etiquetado e propagado para o ramo principal.
